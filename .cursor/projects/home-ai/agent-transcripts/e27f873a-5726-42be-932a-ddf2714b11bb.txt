## 1) DB Schema (Entities + Relations)

### 🔷 Core Identity
**users**
- id (PK)
- email (unique)
- password_hash
- mfa_enabled (bool)
- mfa_type (totp/sms/webauthn)
- status (active/suspended/deleted)
- created_at, updated_at, last_login_at

**user_profiles**
- user_id (PK/FK -> users.id)
- full_name
- phone
- avatar_url
- locale, timezone

**organizations**
- id (PK)
- name
- domain (unique, nullable)
- industry
- status
- created_at, updated_at

**organization_members**
- id (PK)
- organization_id (FK)
- user_id (FK)
- role_id (FK -> roles.id)
- status (active/invited/removed)
- invited_by (FK -> users.id)
- joined_at

---

### 🔷 Authentication & Sessions
**auth_providers**
- id (PK)
- user_id (FK)
- provider (google/apple/azure/saml/oidc)
- provider_user_id
- created_at

**sessions**
- id (PK)
- user_id (FK)
- device_id
- ip_address
- user_agent
- started_at, ended_at
- status (active/revoked/expired)

**api_keys**
- id (PK)
- owner_type (user/org)
- owner_id
- name
- key_hash
- last_used_at
- created_at, revoked_at

---

### 🔷 Authorization (RBAC / ABAC)
**roles**
- id (PK)
- scope (global/org)
- name (Admin/Analyst/Viewer/User/Custom)
- description

**permissions**
- id (PK)
- resource (logs/users/billing/...)
- action (read/create/update/delete/export/...)
- description

**role_permissions**
- role_id (FK)
- permission_id (FK)

**policies** (PBAC/ABAC)
- id (PK)
- organization_id (FK)
- name
- definition_json (policy rules)
- status

---

### 🔷 Plans & Subscriptions
**plans**
- id (PK)
- type (user/company)
- name (Free/Pro/Business/Enterprise)
- price_monthly
- billing_cycle (monthly/yearly)
- status

**plan_features**
- id (PK)
- plan_id (FK)
- feature_key (mfa/sso/api_keys/log_export/siem/...)
- enabled (bool)
- limit_value (nullable int/decimal)
- unit (requests/users/devices/days)

**subscriptions**
- id (PK)
- owner_type (user/org)
- owner_id
- plan_id (FK)
- status (active/trial/paused/canceled)
- start_at, end_at, renewal_at
- billing_provider (stripe/...)
- external_subscription_id

---

### 🔷 Accounting & Logs
**audit_logs**
- id (PK)
- owner_type (user/org)
- owner_id
- actor_user_id (FK)
- event_type (login/logout/permission_change/...)
- resource
- metadata_json
- created_at
- severity (info/warn/critical)

**usage_metrics**
- id (PK)
- owner_type (user/org)
- owner_id
- metric_key (api_calls/log_exports/...)
- value
- period_start, period_end

---

### 🔷 Billing
**invoices**
- id (PK)
- subscription_id (FK)
- amount
- currency
- status (paid/unpaid/failed)
- issued_at, due_at
- provider_invoice_id

**payments**
- id (PK)
- invoice_id (FK)
- amount
- status
- provider_payment_id
- paid_at

---

## 2) Key Relationships (مختصر)
- user ↔ organization_members ↔ organizations (Many-to-Many)
- plans ↔ subscriptions (One-to-Many)
- subscriptions ↔ invoices ↔ payments
- roles ↔ role_permissions ↔ permissions
- organization_members ↔ roles
- policies مرتبطة بالـ organizations (PBAC/ABAC)
