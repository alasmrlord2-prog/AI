# 1️⃣ إنشاء User داخل CRM (User Lifecycle)

### 🔹 أفضل Practice عالمي:

لا تنشئ User مباشرة “active”

### 🔹 Flow صحيح:

1. **Create User (Pending)**
2. **Verify Email**
3. **Assign Tenant (Company / Workspace)**
4. **Assign Role**
5. **Activate User**

### 🔹 User Model (مهم جدًا):

```txt
User
- id
- email
- password_hash
- status (pending | active | suspended)
- tenant_id
- role_id
- email_verified_at
- last_login
```

> ❗ ملاحظة:
> **User لا يملك صلاحيات مباشرة** → الصلاحيات دائمًا من Role

# 2️⃣ Authentication (AuthN) – الدخول للنظام

### ✅ Best Practices:

* JWT **قصير العمر** (15–30 دقيقة)
* Refresh Token (httpOnly cookie)
* MFA (اختياري – enterprise)
* Password hashing (bcrypt / argon2)

### 🔹 Flow:

```text
Login → Verify Credentials
→ Issue Access Token
→ Issue Refresh Token
→ Redirect Dashboard
```

# 3️⃣ Authorization (AuthZ) – الصلاحيات (RBAC)

### 🎯 لا تستخدم:

* if user.is_admin ❌

### ✅ استخدم:

**RBAC + Permissions**

### 🔹 Models:

```txt
Role
- id
- name (admin, analyst, viewer)

Permission
- id
- key (view_dashboard, export_data)

RolePermission
```

### 🔹 Runtime Check:

```python
if not user.has_permission("view_dashboard"):
```

---

## 🔹 Usage Event Model (أساسي):

```txt
UsageEvent

- user_id
- service (siem, api, storage)
- action (query, ingest, export)
- units
- timestamp
```

📌 **كل عملية مهمة → Event**

---

```txt
User runs SIEM query
→ cost = 5 units
→ save UsageEvent
→ increment tenant usage
```

# 5️⃣ Metering Engine (محرك الحساب)

# 4️⃣ كيف نطبّق AAA (Best Practice عالمي)

## 🔐 A) Authentication – التحقق من الهوية

### ✅ الممارسة الأفضل (Recommended Stack)

**Hybrid Authentication**

### 🔹 ماذا نستخدم؟

* **JWT (Access Token)**

  * قصير العمر: `15–30 دقيقة`
* **Refresh Token**

  * طويل العمر
  * محفوظ كـ `httpOnly secure cookie`
* **Optional External IdP**

  * Keycloak / Auth0 / Azure AD (Enterprise)

---

### 🔹 Flow معتمد:

```text
Login
→ Validate credentials
→ Issue Access JWT
→ Issue Refresh Token
→ Attach tenant_id + role_id داخل JWT
```

### 🔹 JWT Payload (مهم):

```json
{
  "sub": "user_id",
  "tenant_id": "org_123",
  "role": "admin",
  "permissions_version": 3,
  "exp": 123456789
}
```

📌 **ليش permissions_version؟**
حتى تقدر تبطل صلاحيات User بدون ما تنتظر انتهاء التوكن.

---

## 🛂 B) Authorization – الصلاحيات

### ✅ المعيار الذهبي:

**RBAC + Fine-Grained Permissions**

---

### 🔹 Structure:

```txt
User → Role → Permissions
```

### 🔹 Models:

```txt
roles
- id
- name (owner, admin, analyst, viewer)

permissions
- id
- key (view_dashboard, run_query, export_data)

role_permissions
```

---

### 🔹 Runtime Enforcement:

* **Backend**: mandatory
* **Frontend**: UX only (ليس أمان)

```python
@require_permission("run_query")
def query_logs():
    ...
```

❌ ممنوع:

* isAdmin flags
* hardcoded roles

---

## 📊 C) Accounting – تسجيل الاستهلاك (الأهم في SaaS)

### ✅ Best Practice عالمي:

**Event-Based Accounting (Usage Events)**

---

### 🔹 ماذا نسجل؟

أي Action له قيمة:

| Action        | Units  |
| ------------- | ------ |
| API call      | 1      |
| SIEM query    | 5      |
| Log ingestion | per MB |
| Export        | 10     |

---

### 🔹 Usage Event Schema:

```txt
usage_events
- id
- tenant_id
- user_id
- service
- action
- units
- source (api / ui)
- timestamp
```

---

### 🔹 Flow:

```text
User Action
→ Emit Usage Event
→ Queue (async)
→ Metering Worker
→ Aggregate usage
```

📌 **ممنوع تحسب usage synchronously** (يضرب الأداء)

# 6️⃣ Audit Logs – المراقبة والتتبع (SOC Mindset)

## ✅ Best Practice:

**Append-only Audit Log (لا يُعدل)**

---

## 🔍 ماذا نسجل؟

### 🔹 Security Events:

* Login / Logout
* Failed login
* MFA changes
* Role / Permission changes

### 🔹 Business Events:

* Plan change
* Usage limit reached
* Billing actions

### 🔹 Data Access:

* Export
* Bulk delete
* Sensitive queries

---

## 🔹 Audit Log Schema:

```txt
audit_logs
- id
- tenant_id
- actor_user_id
- action
- target_type
- target_id
- ip_address
- user_agent
- metadata (JSON)
- timestamp
```

---

### 🔹 Example:

```json
{
  "action": "ROLE_CHANGED",
  "actor": "user_1",
  "target": "user_9",
  "old_role": "viewer",
  "new_role": "admin"
}
```

---

## 🚨 إضافات احترافية:

* Immutable storage
* Retention policy
* Export for compliance
* Stream to SIEM

# 🧠 الخلاصة التنفيذية (TL;DR)

| Layer          | Best Practice                |
| -------------- | ---------------------------- |
| Authentication | JWT + Refresh + Optional IdP |
| Authorization  | RBAC + Permissions           |
| Accounting     | Event-based async metering   |
| Tenant         | tenant_id everywhere         |
| Audit          | Append-only immutable logs   |
