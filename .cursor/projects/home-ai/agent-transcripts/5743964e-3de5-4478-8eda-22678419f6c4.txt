تعمل dependency اسمها `require_feature("monitor")`

مثال:

```python
from fastapi import Depends, HTTPException, status
from app.api.deps import require_auth
from app.core.features import tenant_has_feature

def require_feature(feature_key: str):
    def _dep(user = Depends(require_auth)):
        if not tenant_has_feature(user.tenant_id, feature_key):
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"Feature '{feature_key}' not enabled"
            )
        return user
    return _dep
```

وبعدين:

```python
@router.get("/monitor", dependencies=[Depends(require_feature("monitor"))])
def monitor(...):
    ...
```
