# 🔧 Backend Troubleshooting Guide

## المشكلة الحالية
Backend container يعمل لكن لا يستجيب على port 8000 (Empty reply from server)

## ✅ الحل السريع

```bash
cd /home/ai/ai-agent
./FIX_BACKEND_ISSUE.sh
```

أو مع إعادة بناء:
```bash
./FIX_BACKEND_ISSUE.sh --rebuild
```

---

## 🔍 خطوات التشخيص

### 1. فحص Container Status
```bash
sudo docker ps | grep backend
sudo docker ps -a | grep backend
```

### 2. فحص Logs
```bash
sudo docker logs ai-agent-backend --tail=100
```

ابحث عن:
- Import errors
- Database connection errors
- Port binding errors
- Python syntax errors

### 3. فحص Processes داخل Container
```bash
sudo docker exec ai-agent-backend ps aux
```

يجب أن ترى `uvicorn` process يعمل.

### 4. اختبار Python Import
```bash
cd /home/ai/ai-agent/backend
./test-startup.sh
```

### 5. فحص Database
```bash
sudo docker logs ai-agent-postgres --tail=20
sudo docker exec ai-agent-backend python -c "from app.core.database import engine; print('DB OK')"
```

### 6. فحص Port Binding
```bash
sudo netstat -tlnp | grep 8000
sudo docker port ai-agent-backend
```

## 🛠️ الحلول الشائعة

### الحل 1: إعادة تشغيل Backend
```bash
cd /home/ai/ai-agent/backend
./restart.sh
```

### الحل 2: إعادة بناء Container
```bash
cd /home/ai/ai-agent
docker-compose -f docker-compose.yml build --no-cache backend
docker-compose -f docker-compose.yml up -d backend
```

### الحل 3: فحص Dependencies
```bash
sudo docker exec ai-agent-backend pip list | grep -E "(fastapi|uvicorn|sqlalchemy)"
```

### الحل 4: تشغيل يدوي داخل Container
```bash
sudo docker exec -it ai-agent-backend bash
# داخل container:
cd /app
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### الحل 5: فحص Database Connection
```bash
# Test postgres connection
sudo docker exec ai-agent-backend python -c "
from sqlalchemy import create_engine
import os
db_url = os.getenv('DATABASE_URL')
try:
    engine = create_engine(db_url)
    conn = engine.connect()
    print('✅ Database connection OK')
    conn.close()
except Exception as e:
    print(f'❌ Database error: {e}')
"
```

## 🐛 الأخطاء الشائعة

### 1. Import Error
**الخطأ:** `ModuleNotFoundError: No module named 'app.xxx'`

**الحل:**
```bash
# تأكد من أن PYTHONPATH صحيح
sudo docker exec ai-agent-backend env | grep PYTHONPATH
# يجب أن يكون: PYTHONPATH=/app
```

### 2. Database Connection Error
**الخطأ:** `could not connect to server`

**الحل:**
```bash
# تحقق من postgres container
sudo docker ps | grep postgres
sudo docker logs ai-agent-postgres --tail=20

# تحقق من network
sudo docker network inspect ai-agent_ai-agent-network
```

### 3. Port Already in Use
**الخطأ:** `Address already in use`

**الحل:**
```bash
cd /home/ai/ai-agent
./FIX_PORT_8000.sh
```

### 4. Missing Dependencies
**الخطأ:** `No module named 'xxx'`

**الحل:**
```bash
# إعادة بناء مع تحديث requirements
cd /home/ai/ai-agent
docker-compose -f docker-compose.yml build --no-cache backend
```

## 📋 Checklist

- [ ] Container يعمل: `sudo docker ps | grep backend`
- [ ] Port يستمع: `sudo netstat -tlnp | grep 8000`
- [ ] Uvicorn process يعمل: `sudo docker exec ai-agent-backend ps aux | grep uvicorn`
- [ ] Python import يعمل: `sudo docker exec ai-agent-backend python -c "from app.main import app"`
- [ ] Database متصل: `sudo docker logs ai-agent-postgres`
- [ ] Network صحيح: `sudo docker network inspect ai-agent_ai-agent-network`

## 🚀 الحل النهائي

إذا لم يعمل أي شيء:

```bash
cd /home/ai/ai-agent

# 1. إيقاف كل شيء
cd backend && ./stop.sh
cd ..

# 2. تنظيف
docker-compose -f docker-compose.yml down
docker system prune -f

# 3. إعادة بناء من الصفر
docker-compose -f docker-compose.yml build --no-cache

# 4. تشغيل
cd backend && ./start.sh

# 5. انتظار واختبار
sleep 30
curl http://localhost:8000/health
```
