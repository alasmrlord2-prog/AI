## 🔘 Theme Toggle Button

### استخدام ThemeToggle Component

```tsx
import { ThemeToggle } from "@/components/ui/theme-toggle";

// في أي مكان في الـ UI
<ThemeToggle />
```

### زر بسيط مخصص

```tsx
<button
  onClick={() => {
    const html = document.documentElement;
    html.classList.toggle("dark");
    localStorage.setItem("theme", html.classList.contains("dark") ? "dark" : "light");
  }}
  className="rounded-sw-btn border border-sw-border bg-sw-bg-card px-3 py-2 text-xs text-sw-text-soft hover:bg-sw-bg-hover"
>
  Toggle Theme
</button>
```

## 🎨 Color Usage Guidelines

### Brand Colors (مشتركة بين الوضعين)
- `sw-blue` (#1399FF) - للروابط والأزرار الرئيسية
- `sw-teal` (#00D1CE) - للعناصر الثانوية
- `sw-blue-light` (#4BB8FF) - لحالات hover
- `sw-teal-light` (#2EE3E0) - للتمييزات الخفيفة

### Background Colors (تتغير تلقائياً)
- **Light Mode:**
  - `sw-bg`: #F5F7FA (خلفية الصفحة)
  - `sw-bg-card`: #FFFFFF (الكاردات)
  - `sw-bg-soft`: #EEF1F5 (الأقسام)
  - `sw-bg-hover`: #F0F4F8 (حالات hover)
  
- **Dark Mode:**
  - `sw-bg`: #0A0F16 (خلفية الصفحة)
  - `sw-bg-card`: #121C27 (الكاردات)
  - `sw-bg-soft`: #0E1622 (الأقسام)
  - `sw-bg-hover`: #182332 (حالات hover)

### Text Colors (تتغير تلقائياً)
- **Light Mode:**
  - `sw-text`: #0A1A2F (النص الرئيسي)
  - `sw-text-soft`: #1F2937 (النص الثانوي)
  - `sw-text-muted`: #6B7280 (النص المهمل)
  
- **Dark Mode:**
  - `sw-text`: #FFFFFF (النص الرئيسي)
  - `sw-text-soft`: #C8D1E0 (النص الثانوي)
  - `sw-text-muted`: #8A94A6 (النص المهمل)

### Status Colors (مشتركة)
- `sw-success`: #10B981
- `sw-warning`: #F59E0B
- `sw-danger`: #EF4444

## 📝 Notes

1. **استخدم CSS variables دائماً** - الألوان تتغير تلقائياً بين الوضعين
2. **لا تستخدم ألوان ثابتة** - استخدم فقط `sw-*` classes
3. **Shadows** - استخدم `shadow-sw-card` للـ Light و `dark:shadow-sw-card-dark` للـ Dark
4. **Gradient** - `bg-gradient-to-r from-sw-blue to-sw-teal` يعمل في الوضعين
5. **Theme Toggle** - استخدم `<ThemeToggle />` component
