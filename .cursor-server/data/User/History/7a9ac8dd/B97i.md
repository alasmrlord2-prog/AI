# 📚 الوثيقة الشاملة لمشروع SHIFTWAVE AI Platform

## 🎯 نظرة عامة على المشروع

### ما هو المشروع؟
**SHIFTWAVE AI Platform** هو منصة SaaS شاملة متعددة الواجهات (Multi-Frontend) تعتمد على الذكاء الاصطناعي لإدارة وتشغيل البنية التحتية والخدمات. المشروع يوفر ثلاث واجهات منفصلة تماماً متصلة بـ Backend موحد:

1. **Dashboard (AI Agent)** - واجهة المستخدم العادي للتفاعل مع AI Agent
2. **CRM (Customer Relationship Management)** - إدارة العملاء والاشتراكات
3. **AAA (Authentication, Authorization, Accounting)** - إدارة المصادقة والصلاحيات

### المميزات الرئيسية
- ✅ نظام Multi-Tenancy كامل
- ✅ AI Agent ذكي للتفاعل مع النظام
- ✅ إدارة شاملة للأمان والمراقبة
- ✅ CI/CD مدمج
- ✅ نظام Audit و Logging متقدم
- ✅ واجهات منفصلة لكل خدمة
- ✅ بنية تحتية قابلة للتوسع باستخدام Docker

## 🐳 شرح Dockerfiles و Docker Compose

### 1. Backend Dockerfile (`backend/Dockerfile`)

```dockerfile
FROM python:3.11-slim          # Base image: Python 3.11 slim version

WORKDIR /app                    # Set working directory

# Install system dependencies
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
    gcc \                        # C compiler for building Python packages
    postgresql-client \          # PostgreSQL client tools
    curl \                       # For health checks
    && rm -rf /var/lib/apt/lists/*  # Clean up apt cache

# Copy requirements first for better caching
COPY requirements.txt /app/
RUN pip install --no-cache-dir -r requirements.txt  # Install Python dependencies

# Copy application code
COPY . /app

# Environment variables
ENV PYTHONPATH=/app            # Python path
ENV PYTHONUNBUFFERED=1         # Unbuffered output for logs

EXPOSE 8000                     # Expose port 8000

# Health check
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
  CMD curl -f http://localhost:8000/health || exit 1

# Start command
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**شرح الخطوات:**
1. **Base Image**: يستخدم Python 3.11 slim (صغير الحجم)
2. **System Dependencies**: يثبت gcc للبناء، postgresql-client للاتصال بقاعدة البيانات، curl للـ health checks
3. **Python Dependencies**: ينسخ requirements.txt أولاً (لتحسين caching) ثم يثبت الحزم
4. **Application Code**: ينسخ كود التطبيق
5. **Environment**: يحدد متغيرات البيئة
6. **Health Check**: يتحقق من صحة الخدمة كل 30 ثانية
7. **Start Command**: يبدأ uvicorn server على المنفذ 8000

### 2. Frontend Dockerfile (`frontend/Dockerfile`)

```dockerfile
FROM node:20-alpine            # Base image: Node.js 20 Alpine

WORKDIR /app                   # Set working directory

# Install wget for health checks
RUN apk add --no-cache wget    # Alpine package manager

# Copy package files
COPY package.json package-lock.json* ./

# Install dependencies
RUN npm install --legacy-peer-deps  # Install with legacy peer deps flag

# Copy application code
COPY . .

# Environment variables

EXPOSE 3000                     # Expose port 3000

# Health check
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
  CMD wget --no-verbose --tries=1 --spider http://localhost:3000 || exit 1

# Start command
CMD ["npm", "run", "dev"]       # Run Next.js dev server
```

**شرح الخطوات:**
1. **Base Image**: يستخدم Node.js 20 Alpine (صغير الحجم)
2. **System Dependencies**: يثبت wget للـ health checks
3. **Dependencies**: ينسخ package.json و package-lock.json ثم يثبت الحزم
4. **Application Code**: ينسخ كود التطبيق
5. **Environment**: يعطل Next.js telemetry
6. **Health Check**: يتحقق من صحة الخدمة
7. **Start Command**: يبدأ Next.js dev server

### 3. Docker Compose Configuration (`docker-compose.yml`)

#### PostgreSQL Service
```yaml
postgres:
  image: postgres:15-alpine      # PostgreSQL 15 Alpine image
  container_name: ai-agent-postgres
  environment:
    POSTGRES_USER: aiagent
    POSTGRES_PASSWORD: aiagent123
    POSTGRES_DB: ai_agent_db
  ports:
    - "5432:5432"                # Expose PostgreSQL port
  volumes:
    - postgres_data:/var/lib/postgresql/data  # Persistent storage
  networks:
    - ai-agent-network
  restart: unless-stopped
  healthcheck:
    test: ["CMD-SHELL", "pg_isready -U aiagent"]
    interval: 10s
    timeout: 5s
    retries: 5
```

#### Ollama Service
```yaml
ollama:
  image: ollama/ollama:latest
  container_name: ai-agent-ollama
  ports:
    - "11434:11434"              # Expose Ollama API port
  volumes:
    - ollama_data:/root/.ollama  # Persistent storage for models
  networks:
    - ai-agent-network
  restart: unless-stopped
```

#### Backend Service
```yaml
backend:
  build:
    context: ./backend
    dockerfile: Dockerfile
  container_name: ai-backend
  ports:
    - "8000:8000"
  environment:
    - DATABASE_URL=postgresql://aiagent:aiagent123@postgres:5432/ai_agent_db
    - OLLAMA_URL=http://ollama:11434
    - DEBUG=true
    - LOG_LEVEL=INFO
    - CORS_ORIGINS=["*"]
    - SECRET_KEY=your-secret-key-change-in-production
  volumes:
    - ./backend:/app              # Mount code for hot reload
    - backend_logs:/app/logs      # Persistent logs
  depends_on:
    postgres:
      condition: service_healthy  # Wait for PostgreSQL
    ollama:
      condition: service_started  # Wait for Ollama
  networks:
    - ai-agent-network
  restart: unless-stopped
  command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload --timeout-keep-alive 600 --timeout-graceful-shutdown 30
```

**ملاحظات مهمة:**
- `depends_on`: يضمن أن PostgreSQL و Ollama يعملان قبل Backend
- `volumes`: يربط الكود المحلي للـ hot reload
- `networks`: جميع الخدمات في نفس الشبكة للتواصل

#### 3. Middleware (`middleware.ts`)

**الوظيفة**: توجيه تلقائي بناءً على Domain

**الكود:**
```typescript
export function middleware(request: NextRequest) {
  const hostname = request.headers.get('host') || '';
  const pathname = request.nextUrl.pathname;

  // CRM domain → /crm
  if (hostname.includes('crm.bankid-sy.com')) {
    if (pathname === '/') {
      return NextResponse.redirect(new URL('/crm', request.url));
    }
    if (!pathname.startsWith('/crm')) {
      return NextResponse.redirect(new URL(`/crm${pathname}`, request.url));
    }
  }
  
  // AAA domain → /aaa
  if (hostname.includes('aaa.bankid-sy.com')) {
    if (pathname === '/') {
      return NextResponse.redirect(new URL('/aaa', request.url));
    }
    if (!pathname.startsWith('/aaa')) {
      return NextResponse.redirect(new URL(`/aaa${pathname}`, request.url));
    }
  }

  return NextResponse.next();
}
```

**كيف يعمل:**
1. يتحقق من Domain name
2. يعيد التوجيه تلقائياً إلى المسار الصحيح
3. `crm.bankid-sy.com` → `/crm`
4. `aaa.bankid-sy.com` → `/aaa`
5. `ai-agent.bankid-sy.com` → `/` (Dashboard)

#### 4. Next.js Configuration (`next.config.ts`)

```typescript
const nextConfig = {
  // Allowed origins
  allowedDevOrigins: [
    "ai-agent.bankid-sy.com",
    "crm.bankid-sy.com",
    "aaa.bankid-sy.com",
    "http://localhost:3000",
    "http://localhost:3001",
    "http://localhost:3002",

  // Standalone output for Docker
  output: 'standalone',
  
  // API rewrites to backend
  async rewrites() {
    const backendUrl = 
      process.env.BACKEND_URL || 
      process.env.NEXT_PUBLIC_BACKEND_URL || 
      'http://backend:8000';
    
    return [
      {
        source: '/api/:path*',
        destination: `${backendUrl}/api/:path*`,
      },
    ];
  },
};
```

**كيف يعمل:**
