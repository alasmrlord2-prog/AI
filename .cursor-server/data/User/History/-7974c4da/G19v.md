# 🐳 Docker Setup Guide

## 📋 المتطلبات

- Docker
- Docker Compose

---

## 🚀 التشغيل

### 1. تشغيل كل شيء

```bash
docker-compose up -d
```

هذا رح يشغّل:
- ✅ PostgreSQL Database
- ✅ Backend API
- ✅ Frontend

### 2. التحقق من الحالة

```bash
docker-compose ps
```

### 3. عرض Logs

```bash
# Backend Logs
docker-compose logs -f backend

# Frontend Logs
docker-compose logs -f frontend

# Database Logs
docker-compose logs -f postgres
```

---

## 🛑 الإيقاف

```bash
# إيقاف كل شيء
docker-compose down

# إيقاف مع حذف Volumes
docker-compose down -v
```

---

## 🔄 إعادة التشغيل

```bash
# إعادة تشغيل كل شيء
docker-compose restart

# إعادة تشغيل Backend فقط
docker-compose restart backend

# إعادة تشغيل Frontend فقط
docker-compose restart frontend
```

---

## 🔧 إعادة البناء

```bash
# إعادة بناء كل شيء
docker-compose build --no-cache

# إعادة بناء Backend فقط
docker-compose build --no-cache backend

# إعادة بناء Frontend فقط
docker-compose build --no-cache frontend
```

---

## 🗄️ قاعدة البيانات

### الاتصال بقاعدة البيانات

```bash
# من داخل Container
docker-compose exec postgres psql -U aiagent -d ai_agent_db

# من خارج Container
psql -h localhost -p 5432 -U aiagent -d ai_agent_db
```

**Password:** `aiagent123`

### Backup

```bash
docker-compose exec postgres pg_dump -U aiagent ai_agent_db > backup.sql
```

### Restore

```bash
docker-compose exec -T postgres psql -U aiagent ai_agent_db < backup.sql
```

## 🔍 Troubleshooting

### Backend لا يعمل؟

```bash
# تحقق من Logs
docker-compose logs backend

# إعادة بناء
docker-compose build --no-cache backend
docker-compose up -d backend
```

### Frontend لا يعمل؟

```bash
# تحقق من Logs
docker-compose logs frontend

# إعادة بناء
docker-compose build --no-cache frontend
docker-compose up -d frontend
```

### قاعدة البيانات؟

```bash
# تحقق من الحالة
docker-compose ps postgres

# إعادة تشغيل
docker-compose restart postgres
```

### مشاكل Ports؟

```bash
# تحقق من Ports المستخدمة
lsof -i :8000
lsof -i :3000
lsof -i :5432

# غيّر Ports في docker-compose.yml إذا لزم
```

## 🔐 Environment Variables

### Backend

يتم تمريرها عبر `docker-compose.yml`:
- `DATABASE_URL`
- `SECRET_KEY`
- `CORS_ORIGINS`

### Frontend

يتم تمريرها عبر `docker-compose.yml`:
- `NEXT_PUBLIC_AGENT_API_URL`
- `NEXT_PUBLIC_BACKEND_URL`

---

## 🎯 Production Setup

للتشغيل في Production:

1. **غيّر Secrets:**
   - `SECRET_KEY`
   - `JWT_SECRET_KEY`
   - `POSTGRES_PASSWORD`

2. **غيّر CORS:**
   - `CORS_ORIGINS` → Domain Production

3. **استخدم Production Build:**
   - Frontend: `npm run build` → `npm start`
   - Backend: بدون `--reload`
