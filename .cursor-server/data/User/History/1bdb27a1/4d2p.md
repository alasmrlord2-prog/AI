# 🎨 ShiftWave Dashboard Theme - Quick Start

## 📦 الملفات المطلوبة

تم إنشاء الملفات التالية:

1. **`tailwind.config.js`** - إعدادات Tailwind مع ShiftWave colors
2. **`app/globals.css`** - تم تحديثه بإضافة الخطوط والـ theme colors
3. **`shiftwave-theme.css`** - ملف CSS بسيط يحتوي على جميع المتغيرات
4. **`SHIFTWAVE_THEME_EXAMPLES.md`** - أمثلة استخدام كاملة

---

## 🚀 الاستخدام السريع

### 1. تأكد من تفعيل Dark Mode

في ملف `app/layout.tsx` أو الملف الرئيسي، تأكد من وجود:

```tsx
<html className="dark">
```

### 2. استخدام الألوان في Tailwind

```tsx
// Primary Color
<div className="bg-sw-primary text-white">...</div>

// Gradient Button
<button className="bg-sw-gradient text-white">...</button>

// Card
<div className="bg-sw-bg-card border border-sw-border">...</div>

// Text Colors
<p className="text-sw-text-soft">...</p>
```

### 3. استخدام CSS Variables مباشرة

```css
.my-component {
  background: var(--sw-bg-card);
  color: var(--sw-text);
  border: 1px solid var(--sw-border);
}
```

## 🎯 الألوان الأساسية

| المتغير | القيمة | الاستخدام |
|---------|--------|-----------|
| `sw-primary` | `#1399FF` | الأزرار الرئيسية، الروابط |
| `sw-secondary` | `#00D1CE` | العناصر الثانوية |
| `sw-bg` | `#0A0F16` | خلفية الصفحة |
| `sw-bg-card` | `#121C27` | خلفية الكاردات |
| `sw-text` | `#FFFFFF` | النص الرئيسي |
| `sw-text-soft` | `#C8D1E0` | النص الثانوي |

## ⚠️ قواعد مهمة

1. **لا تستخدم ألوان خارج النظام** - استخدم فقط ألوان ShiftWave
2. **استخدم نظام المسافات الموحد** - `xxs`, `xs`, `sm`, `md`, `lg`, `xl`, `2xl`
3. **Border radius** - `rounded-sw-card` للكاردات، `rounded-sw-btn` للأزرار
4. **Dark mode only** - الداشبورد داكنة دائماً
