# تعليمات إعادة تشغيل الـ Backend

## المشكلة الحالية:
- العملية القديمة (PID 304405) تستخدم `main:app` بدلاً من `app.main:app`
- لا يمكن إيقافها لأنها قد تكون من systemd أو Docker

## الحلول:

### الحل 1: إعادة تشغيل systemd service (إن وجد)
```bash
sudo systemctl restart ai-backend
# أو
sudo systemctl restart uvicorn
```

### الحل 2: إعادة تشغيل Docker container
```bash
cd /home/ai/ai-agent/backend
docker-compose -f backend-compose.yml restart
# أو
docker restart ai-backend
```

### الحل 3: إيقاف يدوي ثم إعادة التشغيل
```bash
# إيقاف العملية (قد تحتاج sudo)
sudo kill -9 304405

# أو إيقاف كل شيء على المنفذ 8000
sudo fuser -k 8000/tcp

# ثم إعادة التشغيل
cd /home/ai/ai-agent/backend
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload > backend.log 2>&1 &
```

### الحل 4: استخدام منفذ مختلف مؤقتاً
```bash
cd /home/ai/ai-agent/backend
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload > backend.log 2>&1 &
```

ثم تحديث `API_URL` في الـ frontend إلى `http://localhost:8001`

## التحقق من التشغيل:
```bash
# التحقق من العملية
ps aux | grep uvicorn

# التحقق من الـ API
curl http://localhost:8000/api/health

# رؤية الـ logs
tail -f /home/ai/ai-agent/backend/backend.log
```
