# فحص وصول Backend - Backend Access Check

## المشكلة:
Backend شغال على `localhost:8000` لكن غير قابل للوصول من IP الخارجي (`3.79.231.29:8000`)

## الحلول:

### 1. تحقق من أن Container يستمع على 0.0.0.0:
```bash
cd /home/ai/ai-agent/backend
docker compose -f backend-compose.yml logs | grep "running"
```

يجب أن ترى:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 2. تحقق من Port Mapping:
```bash
docker ps | grep ai-backend
```

يجب أن ترى:
```
0.0.0.0:8000->8000/tcp
```

### 3. فتح Firewall (إذا كان Ubuntu/Debian):
```bash
# تحقق من حالة Firewall
sudo ufw status

# افتح port 8000
sudo ufw allow 8000/tcp
sudo ufw reload
```

### 4. فتح Security Group (إذا كان AWS EC2):

في AWS Console:
1. اذهب إلى EC2 → Security Groups
2. اختر Security Group الخاص بالـ instance
3. Inbound Rules → Edit
4. أضف Rule:
   - Type: Custom TCP
   - Port: 8000
   - Source: 0.0.0.0/0 (أو IP محدد)
   - Save

### 5. اختبار الوصول:

#### من داخل السيرفر:
```bash
curl http://localhost:8000/api/settings
curl http://127.0.0.1:8000/api/settings
curl http://172.31.20.228:8000/api/settings  # Private IP
```

#### من خارج السيرفر:
```bash
# من جهاز آخر
curl http://3.79.231.29:8000/api/settings
```

### 6. إذا كان Backend على Private IP فقط:

إذا كان Backend يجب أن يكون على Private Network فقط، استخدم Reverse Proxy (Nginx):

```nginx
# /etc/nginx/sites-available/ai-backend
server {
    listen 80;
    server_name 3.79.231.29;

    location / {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 7. حل بديل: استخدام Nginx Reverse Proxy

إذا كان Backend يجب أن يبقى على localhost، استخدم Nginx:

```bash
# تثبيت Nginx
sudo apt update
sudo apt install nginx

# إنشاء config
sudo nano /etc/nginx/sites-available/ai-backend

# Paste الـ config أعلاه

# Enable site
sudo ln -s /etc/nginx/sites-available/ai-backend /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 8. اختبار نهائي:

بعد فتح Firewall/Security Group:
```bash
# من خارج السيرفر
curl -v http://3.79.231.29:8000/api/settings

# يجب أن ترى:
# * Connected to 3.79.231.29 (3.79.231.29) port 8000
# * HTTP/1.1 200 OK
```

## ملاحظات:

- **Security:** فتح port 8000 للعالم قد يكون خطراً. استخدم:
  - Authentication
  - Rate limiting
  - HTTPS (TLS)
  - IP whitelist إذا أمكن

- **Development:** يمكن استخدام SSH tunnel:
  ```bash
  ssh -L 8000:localhost:8000 user@3.79.231.29
  ```
  ثم Frontend يتصل بـ `localhost:8000`
