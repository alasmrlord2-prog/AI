# 🚀 البدء السريع - Quick Start

## خطوتان فقط!

### 1️⃣ تشغيل الباك إند
```bash
cd backend
./start_backend.sh
```

### 2️⃣ تشغيل الفرونت إند
```bash
cd frontend
./start_frontend.sh
```

## ✅ جاهز!

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Docs: http://localhost:8000/docs

---

## 📋 أوامر أخرى

### إيقاف
```bash
# Backend
cd backend && ./stop_backend.sh

# Frontend
cd frontend && ./stop_frontend.sh
```

### إعادة التشغيل
```bash
# Backend
cd backend && ./restart_backend.sh

# Frontend
cd frontend && ./restart_frontend.sh
```
